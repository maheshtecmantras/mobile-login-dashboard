# Mobile Login Dashboard (React)

Responsive React + Vite login and dashboard application with local demo authentication.

## Preview

```bash
npm install
npm run dev
```

The Vite server listens on `0.0.0.0:5173` so hosted preview environments can access it. The production preview command is also available:

```bash
npm run build
npm run preview
```

Use any valid email address and a password with at least six characters.
